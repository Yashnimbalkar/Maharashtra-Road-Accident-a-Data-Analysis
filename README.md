# Maharashtra Road Accident Data Analysis

## 📌 Overview
This project analyzes road accident data from Maharashtra to identify trends, causes, and high-risk areas. The goal is to gain insights that can support road safety improvements and data-driven decision-making.

## 📊 Dataset
- **File:** Maharashtra Road Accident a Data Analysis.xlsx
- **Format:** Excel (.xlsx)

## 🎯 Objectives
- Analyze accident trends across years and districts
- Identify major causes of accidents
- Compare fatal and non-fatal accidents
- Highlight accident-prone regions

## 🛠️ Tools Used
- Microsoft Excel
- Data Cleaning & Preprocessing
- Pivot Tables & Charts

## 🔍 Analysis Performed
- Year-wise and district-wise accident analysis
- Cause-wise accident distribution
- Fatal vs non-fatal accident comparison
- Trend visualization using charts

## 📈 Key Insights
- Certain districts consistently report higher accident rates
- Human factors and speeding are major contributors
- Accidents peak during specific time periods
